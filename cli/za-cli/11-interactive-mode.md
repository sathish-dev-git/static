## 1. Start, requirements, startup flow

```bash
za-cli                    # active profile
za-cli -p staging         # another profile for this session
ZA_CLI_NO_ANIM=1 za-cli   # skip the intro animation / spinner
```

Requirements: a **logged-in profile**, a **real terminal** (raw mode + alternate screen via JLine/Jansi), and the profile **passphrase**.

Startup sequence and exact messages:

| Step | On screen |
|---|---|
| Profile via `-p` does not exist | `✗  Profile '<name>' does not exist.` / `Run 'za-cli profile list' to see available profiles.` → exit 1 |
| Not logged in | `⚠  Not logged in` / `Run 'za-cli login' to authenticate.` → exit 1 |
| No console (piped / CI) | `✗  No console available. Run in a terminal.` (stderr) |
| No profiles at all | `No profiles configured. Run: za-cli login` |
| Banner line | `Profile: <name>` |
| Passphrase prompt | `  Passphrase: ` (masked), up to **3 attempts** |
| Blank passphrase | `✗  No passphrase provided.` (exit immediately, no retry) |
| Wrong passphrase | `⚠  Incorrect passphrase. Attempt 1/3`, `… Attempt 2/3`, then `✗  Incorrect passphrase. Maximum attempts reached.` |
| Success | ASCII-art "ZA CLI" intro (orange gradient, ~2.2 s, any key skips; disabled by `ZA_CLI_NO_ANIM` or no-colour terminals; falls back to `=== Zoho Analytics CLI ===` without Unicode) → Organization menu |

On exit (or Ctrl+C) the terminal is restored by a shutdown hook.

## 2. Screen anatomy

```text
  ◆ 📁 Workspaces  ·  3/17                      ← title · position counter (or "N/M matches", "N selected", "N lines")
    Zoho Analytics › Workspaces                 ← breadcrumb (child first) when the title contains " — "
    17 workspace(s)                             ← subtitle
  Status: ✓ Created 'Sales 2026' (ID: 2148…)    ← one-shot toast from the previous action

  ❯ 📁 Sales Analytics
    📁 Marketing
    📁 HR Reporting
    ▼ 14 more below

  ⌘ ‹↑↓› navigate  ·  ‹enter› open  ·  ‹i› info  ·  ‹c› create  ·  ‹x› command  ·  ‹r› refresh  ·  ‹v› response  ·  ‹b› back  ·  ‹q› quit  ·  ‹/› search  ·  ‹?› commands
```

Menus/cards are capped at 120 columns (90 % of terminal width); data grids use the full width (up to 400). Long lists scroll with the cursor kept centred; selection **wraps** at both ends. Emoji icons disappear on terminals without emoji support; box characters fall back to ASCII (`+ - |`).

## 3. Global keys

| Key | Action |
|---|---|
| `↑` `↓` | Move (wraps). Also `Esc[A/B`, `EscOA/OB`, Windows scan codes. |
| `Enter` | Open / run / confirm |
| `b` or `Esc` | Back one screen — **if a filter is active, the first press clears the filter instead** |
| `q` | Quit za-cli (from an overlay: close it) |
| `/` | Live fuzzy filter of the current list (see § 4) |
| `?` | Command palette listing every key valid on this screen |
| `x` | Show the equivalent **direct CLI command** for the highlighted item / current screen |
| `v` | Show the **raw JSON response** from Zoho Analytics (pager) |
| `i` | Details / columns of the highlighted item |
| `r` | Refresh the current list |
| `c` | Create (workspace, folder, group, …) |
| `a` | Add (users) — in multi-select: select all / clear all |
| `d` | Delete / remove highlighted item |
| `e` | Export (where offered) |
| `f` `g` `u` `t` `s` | Folders / Groups / Users / Trash / Subscription shortcuts where a screen maps them |
| `n` `p` | Next / previous page in table screens (page = rows that fit the terminal, max 40) |
| `PgUp` `PgDn` `Home` `End` | Scroll in tables and long detail cards |
| `Space` | Toggle item in multi-select screens |
| `y` `n` | Answer a yes/no confirmation (`Esc` = no) |
| `Ctrl+C` | Quit (terminal restored) |

Every letter is consumed by the menu loop; an unhandled key just re-renders.

### The `x` screen (learn the typed command)

```text
  ⌘  CLI Direct Command
  ────────────────────────────────────────

  $ za-cli view share -w 2148712000000012345 2148712000000054321 --email alice@example.com --permission read --permission export -P <passphrase>

  Tip: Add -P <passphrase> for non-interactive use

  Press Enter to go back…
```

Every hint is generated by a pure function and unit-tested against the real picocli command tree, so it is runnable as printed.

### The `v` screen (raw response)

```text
  ◆ API Response  ·  42 lines
  ──────────────────────────────────────────────────
  {
    "workspaceId": "2148712000000012345",
    "workspaceName": "Sales Analytics",
    …
  ▼ 30 lines below

  ⌘ ‹↑↓› scroll  ·  ‹n/p› page  ·  ‹Enter/q› back
```

### Message panels, confirmations, review screens

- Result panel icons: `✓` success · `✗` error · `⚠` warning · `●` info. Footer `x CLI command  •  r response  •  Enter continue` (note **`r`**, not `v`, opens the response from a message panel).
- Confirmation: `? Permanently delete workspace 'Sales Analytics'? This cannot be undone.` then `y yes    n no`.
- Multi-step actions end in a **Review — <Action>** screen listing every value; footer `Enter run  •  b edit  •  q cancel  •  ? commands`. `b` loops back to re-enter values.
- Prompts leave raw mode: `  ? Workspace name: ` · secrets are masked · file paths get Tab completion (`(Press Tab to autocomplete file paths)` then `  File: `) · multi-line input ends with an empty line (`  > ` per line).
- Long operations show a braille spinner (`⣾⣷⣯⣟⡿⢿⣻⣽`) with a label such as `Loading workspaces...`.

## 4. Filtering with `/`

Press `/`, type, watch the list narrow live (`🔍 Search: sal▌`, header shows `2/17 matches`). Matching is **fuzzy**, case-insensitive, scored over both the label and its hint: substring matches rank highest (prefix bonus), then subsequence matches with word-boundary bonuses; results are sorted by score. `Enter` confirms the filter (subtitle gains `filter: sal (2/17)`, footer gains `Esc clear filter`); `Esc`/`b` clears it. Empty result:

```text
No matching items
Press / to search again or Esc to clear the filter
```

`showTable` grids (columns, preview, share info, search results, resources) do **not** support `/`; they page with `n`/`p`.

## 6. Workspace menu

Title `📁 <workspaceName>` · subtitle `Workspace ID: <id>`

| Item | Hint | `x` shows |
|---|---|---|
| 📈 **Views** | Browse tables, charts, and dashboards | `za-cli view list -w <ws> -P <passphrase>` |
| ➕ **Create View** | Create a table, query table, chart, summary, or pivot | `za-cli view create-table -w <ws> --name <name> --column "Col:TYPE" …` |
| 📁 **Folders** | Manage workspace folders | `za-cli workspace folders <ws> …` |
| 👥 **Groups** | Manage user groups | `za-cli workspace groups <ws> …` |
| 👤 **Workspace Users** | View and manage workspace members | `za-cli workspace users add <ws> <email> …` |
| 🗑️ **Trash** | View and restore deleted items | `za-cli workspace trash <ws> …` |
| 📡 **Datasources** | Connected data sources | `za-cli workspace datasources <ws> …` |
| 🔄 **Rename Workspace** | Rename this workspace | `za-cli workspace rename <ws> --name "<new-name>" …` |
| 🗑️ **Delete Workspace** | Permanently delete this workspace | `za-cli workspace delete <ws> …` |
| 🔍 **Search** | Find a table, chart, or column by keyword in this workspace | `za-cli search <query> --workspace <ws> …` |

### Views
Views are bucketed by type: **tables** (`table`, `querytable`, `tabularview`, and unknown types) shown as `📊`, **charts/reports** (`chart`, `pivot`, `summary`, `report`, `kpi`, `analysisview`) as `📈`, **dashboards** as `📋`. Subtitle `N tables, M charts, K dashboards`. `i` opens a *View Details* card. Enter opens the Table, Chart or Dashboard menu.

### Create View
Submenu `Table` · `Query Table` · `Chart` · `Summary Report` · `Pivot Report`:

| Flow | Prompts (in order) | Notes |
|---|---|---|
| Table | `Table name` → repeated `Column "Name:TYPE" (blank to finish)` | Malformed → `Use the form Name:TYPE, e.g. Region:PLAIN`. No columns → `No columns provided; table not created.` |
| Query Table | `Query table name` → multi-line `SQL SELECT query` | |
| Chart | `Chart name` → base-table picker (`Select base table`) → chart type `bar / line / pie / scatter / bubble` → `X-axis column`, `X-axis operation (e.g. actual, dimension, year)`, `Y-axis column`, `Y-axis operation (e.g. sum, count, average)` | No tables → `No tables found in this workspace. Create a table first.` |
| Summary Report | `Report name` → base table → repeated `Group-by field "column:table:operation" (blank to finish)` → repeated `Aggregate field …` | Either empty → `A summary needs at least one group-by and one aggregate field.` |
| Pivot Report | `Report name` → base table → `Row`, `Column`, `Data` field entries | All empty → `Provide at least one row, column, or data field.` |

### Folders / Groups
Rows `📁 <name>` (hint `ID: <folderId>`) / `👥 <name>` (hint = description). `c` create (`New folder name` / `New group name` + `Member emails (comma-separated, optional)`), `d` delete with confirmation `Delete folder '<name>'?` / `Delete group '<name>'?`. Empty state rows: `📁 (no folders yet)` · `👥 (no groups yet)`.

### Workspace Users
Panel `EMAIL ID / ROLE / STATUS`; inactive users dimmed. `a` → `Email addresses (comma-separated)` then `Role (e.g. viewer, editor, admin)` (blank = `viewer`) → `Added N user(s) as <role>`. `d` → `Remove user '<email>'?`.

### Trash
Rows `🗑️ <viewName>` (hint = type). **Enter = restore** (`Restore '<name>'?`), `d` = purge (`Permanently delete '<name>'? This cannot be undone.`). Empty: `🗑️ (trash is empty)`.

### Datasources (three levels)
1. List with panel header `CONNECTOR / SOURCE / STATUS / SYNCS / LAST SYNC` (status shows `N schedule groups` when a connection has several intervals).
2. Schedule chooser (only when > 1 interval): rows `🔄 <schedule>` with hints like `Active  ·  3 table(s)  ·  syncs 12/50  ·  next 2026-09-23 02:00`.
3. Schedule detail table `Table / Source / Status / Last Sync`; no tables → `No synced tables here.`
`x` on levels 2–3 shows `za-cli workspace datasources <ws> --detail …`.

### Rename / Delete Workspace
`New workspace name` → `Workspace renamed to: <name>`. Delete: confirm `Permanently delete workspace '<name>'? This cannot be undone.` → `Deleted workspace '<name>'` → back to the org menu.

### Search (workspace-scoped only)
Prompt `Search query (e.g. "churn")`. Always scoped to this workspace (so column names are searched too). Results table `Score / Matched On / View / Column`; none → `No matches for "<query>" in <workspaceName>.` Org-wide search is deliberately not offered here (one request per workspace could trip rate limits); use `za-cli search` or the MCP tool for that.

### Add Column data types (interactive offers 12; the CLI only 8)

| Type | Hint | Type | Hint |
|---|---|---|---|
| `PLAIN` | Plain text | `CURRENCY` | Currency value |
| `MULTI_LINE` ★ | Multi-line text | `PERCENTAGE` ★ | Percentage |
| `EMAIL` | Email address | `DATE` | Date/time |
| `NUMBER` | Integer | `BOOLEAN` ★ | True/false |
| `POSITIVE_NUMBER` | Positive integer | `URL` | URL link |
| `DECIMAL_NUMBER` | Decimal | `AUTO_NUMBER` ★ | Auto-increment |

★ = interactive-only; `za-cli view add-column --type` does not accept these.

### Guided criteria picker (Update Row / Delete Rows)

1. **Select Column** — real schema columns with type hints (no free typing).
2. **Select Operator**:

| Label | Generates |
|---|---|
| Equals | `"Col" = 'value'` |
| Not equals | `"Col" != 'value'` |
| Contains | `"Col" LIKE '%value%'` |
| Greater than / Less than | `"Col" > 'value'` / `"Col" < 'value'` |
| Greater or equal / Less or equal | `"Col" >= 'value'` / `"Col" <= 'value'` |

   (`IN`, `NOT IN`, `BETWEEN` are deliberately not offered.)
3. **Value** — `Value for "<column>" (equals)`; blank cancels. Double quotes in column names and single quotes in values are doubled automatically.

**Affected-row preview**: `Checking affected rows...` runs a criteria-scoped export capped at 1001 records and reports `42 row(s)` or `more than 1000 rows`. Zero matches → `No rows match that criteria — nothing to update.` / `… nothing to delete.` and the flow loops instead of running. Known limitation: a literal `%` or `_` in a *Contains* value is not escaped (SQL wildcard semantics).

### Share View permission presets

| Preset | Grants |
|---|---|
| Read only | `read` |
| Read + Export | `read`, `export` |
| Read + Export + Drill Down | `read`, `export`, `drillDown` |
| Custom permissions | Checklist of all 13 flags with one-line hints (`read` View the data · `export` Export/download the data · `vud` View underlying (raw) data behind a summary · `drillDown` · `addRow` · `updateRow` · `deleteRow` · `deleteAllRows` · `importAppend` · `importAddOrUpdate` · `importDeleteAllAdd` · `share` Re-share with other users · `discussion` Post and view discussion comments). If `read` is missing it is added: `'read' is required for any other permission to grant access — added automatically.` |

Group sharing is temporarily disabled in 1.0.0 (email-based only).

## 10. Interactive vs direct CLI — what differs

| | Interactive | Direct CLI |
|---|---|---|
| Criteria | Guided picker, preview of affected rows, double confirmation on delete | Typed `--criteria`, no preview; use `--dry-run` and a trial `export --criteria` |
| Confirmation policy flags | Own built-in prompts; `--yes` / `--require-confirmation` do not apply | Applies |
| `--dry-run` | Not available | Available |
| Output shaping (`-o`, `--fields`, `--filter`) | Fixed layouts | Available |
| Search | Workspace-scoped only | Org-wide or `-w` |
| Column types | 12 | 8 |
| Sharing grant/revoke | Table menu only | Any view |
| Learning aid | `x` prints the typed command | — |

## 12. Known limitations (1.0.0)

- Switching profile inside the session does not re-authenticate; restart za-cli.
- Group-based sharing is disabled in the Share View / Remove Share flows.
- The affected-row count and the actual mutation are two separate API calls; concurrent edits can make them differ.
- `Contains` does not escape `%`/`_`.
- Hidden **AI Chat** / **Configure AI** menu entries exist in source but are not enabled in this release.
